一、字符串处理工具类

1、StringUtils

2、AntPathMatcher

是一个强大的路径匹配工具，它基于 Ant 风格的路径模式进行匹配。

提取路径变量：

3、PatternMatchUtils

封装了简单的模式匹配功能，主要用来判断字符串是否匹配指定的模式，与AntPathMatcher的关系是：AntPathMatcher功能强大，支持复杂路径匹配；PatternMatchUtils简化版，适合简单的模式匹配场景。

4、PropertyPlaceholderHelper

一个属性占位符解析工具类，专门用来解析字符串中的占位符，比如${...}或#{...}。



二、集合和数组工具类

1、CollectionUtils

2、MultiValueMap

一个特殊 Map 接口，它允许一个键对应多个值。这与普通的 Map<K, V> 不同，普通 Map 中一个键只能对应一个值。

3、ConcurrentReferenceHashMap

4、SystemPropertyUtils

一个系统属性工具类，专门用来解析和处理字符串中的系统属性占位符（比如 ${…}）。
主要功能：
（1）解析字符串中的 ${…} 占位符
（2）替换为实际的系统属性值
（3）支持默认值设置
（4）处理嵌套属性解析

五、Web相关工具类

1、WebUtils

2、UriUtils

3、UriComponentsBuilder

4、ContentCachingRequestWrapper

一个 请求内容缓存包装器，它允许你多次读取 HTTP 请求的 body 内容。
它解决了 HTTP ServletRequest 的一个关键限制：HttpServletRequest 的输入流只能读取一次。

5、HtmlUtils

一个 HTML 转义和反转义工具类，主要用于防止 XSS（跨站脚本攻击）和处理 HTML 特殊字符。
