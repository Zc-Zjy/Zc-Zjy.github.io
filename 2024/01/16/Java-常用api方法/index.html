三、Collections 工具类

Collections 是一个操作Set，List，Map等的集合工具类，位于java.util包下（在rt.jar包中）。

1、常用的类

1、ArrayList：适合读多写少；
2、LinkedList：适合新增、修改、删除操作；
3、HashMap：日常键值存储；
4、LinkedHashMap：要顺序，就它了；

5、TreeMap：需要自动排序；

6、ConcurrentHashMap：并发写Map，就它了；

7、CopyOnWriteArrayList：读多写少的并发 List；

8、ArrayDeque：队列和栈，首选它。

八、BigDecimal用法

1、强烈建议
（1）使用BigDecimal构造对象时，优先使用String构造方法来进行构造，例子：BigDecimal a = new BigDecimal("0.1")；
（2）如果使用double构造方法，请这样操作：先使用Double.toString(double)方法，然后使用BigDecimal(String)构造方法，将double转换为String，要获取该结果，请使用static valueOf(double)方法。

九、Lombok同时使用@Data和@Builder坑

1、说明
（1）使用@Data可以生成无参构造和get、set方法；
（2）使用@Builder可以生成有参构造；
（3）同时使用时，是不会生成无参构造的，如果手动加上无参构造会造成无参构造器报错，编译不通过。
2、解决办法
（1）方法一
同时使用时，如果要生成无参构造，需要在代码里面手动引入注解@Tolerate，让Lombok在生成类的时候，对指定的构造函数不感知。

（2）方法二
直接使用无参构造 + 有参构造的方式，@RequiredArgsConstructor来构建有参，@NoArgsConstructor来构建无参。

十二、JDK8-21实用特性详解

1、JDK8-Lambda表达式

2、JDK8-Stream API

Stream 是对集合的函数式操作接口，支持链式调用、惰性求值、并行处理。它不存储数据，而是从数据源（集合、数组等）中提取并转换。
中间操作：filter, map, sorted, distinct, peek（返回 Stream）。
终端操作：forEach, collect, reduce, count, anyMatch（触发计算）。

3、JDK8-Optional

用于包装可能为 null 的值，强制开发者显式处理空值，避免 NullPointerException。

4、JDK8-java.time包（新的日期时间API）

替代 Date, Calendar, SimpleDateFormat，线程安全、不可变、清晰。

5、JDK11-生产级增强 HttpClient（标准库）

JDK 11正式引入了 java.net.http.HttpClient，替代老旧的 HttpURLConnection。它支持：同步与异步请求、HTTP/2 默认支持、流式 Body 处理（JSON、文件等）、支持 HTTPS、代理、超时设置。

6、JDK11- var 局部变量类型推断

var 允许编译器根据初始化表达式自动推断变量类型，减少冗余声明，提升可读性，var不是动态类型！它在编译期推断类型，运行期不可变。

7、JDK11- String 新方法

JDK 11 增强了 String 类，新增多个实用方法，提升字符串处理能力。

8、JDK17- Record 不可变数据载体

record 是一种特殊的类，用于封装不可变数据。它自动提供：构造器、equals() / hashCode() / toString()、getter 方法（name() 而非 getName()）、canEqual 安全比较。

9、JDK17- sealed classes 密封类

限制哪些类可以继承或实现某个类/接口，增强类型安全性，配合 switch 和模式匹配使用。

10、JDK21（LTS）-虚拟线程

虚拟线程是 Project Loom 的核心成果，是一种轻量级线程，由 JVM 管理，可在单个操作系统线程上运行成千上万个虚拟线程，极大提升 I/O 密集型应用的吞吐量。
传统线程（Platform Thread）：1:1 映射 OS 线程，创建成本高。
虚拟线程：M:N 映射，轻量、低成本、自动调度。

11、JDK21（LTS）-模式匹配switch

允许在 switch 中直接匹配类型并解构 record，避免冗长的 instanceof + 强制转换。
